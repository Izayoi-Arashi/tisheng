# 题库格式

本文档描述 Tisheng 的题库数据格式。内置的 \`src/bank.js\` 与用户导入的题库使用同一格式；文中引用的行号语义以 \`src/worker.js\` 实际实现为准。

## 总览

- \`src/bank.js\`：内置示例题库（3 道通用示例题 + 1 个示例模块），ES Module 导出 \`BANK_VERSION\`、\`QUESTIONS\`、\`MODULES\`
- \`src/bank-corrections.js\`：文本纠错表，导出 \`CORRECTIONS_VERSION\` 与 \`CORRECTIONS\`
- 云备份中的题库对象形状：\`{ id, name, v, modules, questions }\`

## QUESTIONS 条目

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| \`i\` | number | 是 | 题目 id，正整数，全库唯一；学习进度按它索引 |
| \`q\` | string | 是 | 题干 |
| \`o\` | Option[] | 是 | 选项数组，2-8 个 |
| \`a\` | string | 是 | 答案，由选项键组成的多字符字符串（如 \`"A"\` 或 \`"ABD"\`） |
| \`c\` | string | 否 | 分类（章节）；缺省按 \`"未分类"\` 处理 |
| \`x\` | string | 否 | 解析；判分接口返回给用户（缺失时为 \`null\`） |

Option 结构：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| \`k\` | string | 选项键（单字符，如 \`"A"\`）；\`a\` 的每个字符必须都能在选项键中找到 |
| \`t\` | string | 选项文本 |

### 判分与多选语义

- 多选题 = \`a\` 的长度大于 1（\`GET /api/mybank\` 返回的 \`m\` 字段即据此计算）
- 服务端判分：把用户提交的选择与 \`a\` 分别拆成字符、排序、再拼接后做字符串比较，因此用户乱序提交多选也能判对
- 答案只存在于服务端与用户自己的备份中；日常刷题接口不下发 \`a\`

## MODULES 条目

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| \`name\` | string | 模块（章节）名 |
| \`qids\` | number[] | 归属该模块的题目 id 列表 |

内置题库的 \`MODULES\` 手工维护；通过 \`PUT /api/mybank\` 导入题库时，模块由服务端按每题的 \`c\` 字段自动归并生成，无需提交。

## 导入校验（PUT /api/mybank）

- 题库至少 50 题
- \`i\` 必须是正整数且不重复
- 每题必须有 \`q\`、2-8 个选项，且 \`a\` 的每个字符都在选项键中
- 导入会整体替换云备份题库，版本号 \`v\` 自增；客户端检测到版本变化会自动拉取新题库

## 纠错表（bank-corrections.js）

\`CORRECTIONS\` 以题目 id 的字符串形式为键（如 \`"40"\`），值为：

\`\`\`json
{
  "q": { "from": "截断的旧题干", "to": "完整题干" },
  "o": { "A": { "from": "截断的选项文本", "to": "完整的选项文本" } },
  "x": { "from": "截断的解析", "to": "完整的解析" }
}
\`\`\`

- 仅收录「现有文本是 \`to\` 的严格前缀」的截断条目；应用时若发现冲突会抛错，绝不静默改写
- 只覆盖题干、选项文本、解析三处文本，答案、题号、分类一律不动，学习进度（按 \`i\` 索引）因此不受影响
- Worker 读取云备份时使用安全版 \`applyCorrectionsSafe\` 自动补全：匹配不上的条目（如用户自行导入的题库）一律跳过，返回全 0 表示无改动

## 云备份与本地导入的关系

- 每个账号有**一个云备份槽位**（KV 键 \`ub:{uid}\`），保存完整题库（含答案）与学习进度（\`p:{uid}\`），跨设备同步
- \`PUT /api/mybank\` 上传的题库即云备份；\`GET /api/mybank\`（不带 \`full=1\`）返回**剔除答案**的题面用于刷题，带 \`full=1\` 才返回完整数据（备份/下载场景）
- 用户也可以把题库导入为**本地题库**（仅存浏览器，含答案、本地判分、进度不出设备），数量不限
- 删除云备份后，下次访问会自动用内置示例题库重新种子（空进度）
